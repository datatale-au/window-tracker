# Changelog

## 1.0.1

- Works with VS Code instances started with their own `--user-data-dir`: switching goes to the right instance
- `VS_TRACKER_HOME` keeps a separate set of tracked windows, e.g. for demos

## 1.0.0

First public release.

- Panel listing every open VS Code window with its Claude Code status, with this window pinned on top
- Click a window to bring it forward and put the cursor in its Claude chat box
- Badge, status bar count and pop-ups for windows waiting on you
- Expandable details: Claude's question or last reply, background jobs by name, and open Power BI, Word, PowerPoint and Excel documents
- Warnings when a document window stops responding or Power BI shows an error dialog
- Tile or stack all windows on the current screen
